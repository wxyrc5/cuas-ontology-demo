# 本地运行说明（Windows）

## 第一次运行

在 PowerShell 中进入 `06_部署脚本`，依次执行：

```powershell
.\安装本地环境.ps1
.\启动本地项目.ps1
```

浏览器访问 `http://127.0.0.1:8501`。按 `Ctrl+C` 停止服务。

如 PowerShell 阻止本地脚本，可只对当前窗口临时放行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

## Jupyter 复现与修改

```powershell
.\启动Jupyter.ps1
```

脚本会把 JupyterLab 根目录固定到 `05_Notebook与数据`，避免误改其他目录。默认地址为 `http://127.0.0.1:8888`。

## 已验证环境

- Windows
- Python 3.11.15
- Streamlit 1.61.1
- Plotly 6.9.0
- RDFLib 7.6.0
- NumPy 2.4.6
- pandas 3.0.5

直接依赖及已验证版本记录在 `06_部署脚本/requirements-local.txt`；Conda 入口记录在 `06_部署脚本/environment.yml`。

## 项目入口与版本边界

- 唯一本地入口：`03_源码/streamlit_app/app.py`
- 云端镜像：`03_源码/streamlit_cloud_deploy`
- 镜像同步：`06_部署脚本/sync_streamlit_deploy.ps1`
- 二维/三维页面：`03_源码/streamlit_app/pages/5_🗺_机场反无.py`
- 离线地图：`03_源码/streamlit_app/static/maps`

二维地图不依赖演示现场网络；三维视图与二维视图共享同一随机种子、轨迹和拦截事件。

## 演示或交付前验收

从项目根目录运行：

```powershell
.\06_部署脚本\执行技术验收.ps1
```

脚本会重跑四个 Notebook、两轮页面测试、同步部署镜像、执行跨文件终审，并生成 `07_文档/当前技术版本清单.json`。当前包没有 Git 仓库；在建立 Git 基线前，应使用清单中的快照编号和源文件树 SHA-256 区分版本。

如只检查应用能否在真实本地服务中启动、返回健康状态并完成进程清理：

```powershell
.\06_部署脚本\smoke_test_streamlit.ps1
```

机器可读结果写入 `05_Notebook与数据/验证输出/live_streamlit_smoke.json`；运行日志写入 `.runlogs`，不进入发布包。
